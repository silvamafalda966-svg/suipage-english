# 随页英语

个人英语练习网页：认读卡片、纸上听写、理解与拼写独立复习、复习日历，以及词库导入导出。

## 使用

- 从 GitHub Pages 地址打开，无需登录账号。
- iPhone 使用 Safari，先在听写页试听中英文。
- 首页右上角“复习日历”可查看过去、今天、未来的安排。
- Safari 分享菜单中选择“添加到主屏幕”，可作为桌面应用使用。
- 首次完成缓存后可离线打开；声音服务是否离线由设备决定。

## 数据

学习数据保存在当前浏览器的 localStorage，不上传到 GitHub。请定期从“导入导出”下载 JSON 备份。更换域名、浏览器或设备时，需要从旧版本导出 JSON，再在新版本恢复。

## 部署

这是可直接发布的静态文件。在仓库 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 / (root)。资源路径支持仓库子目录，无构建依赖。
